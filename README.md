# Sistema de Gerenciamento de RPG

## Criação das Entidades Iniciais

### Criando o Primeiro Personagem
Para criar seu primeiro personagem, use a seguinte estrutura JSON( o personagem pode ser criado sem uma lista de itens magicos, e 
o item mágico pode ser criado sem personagem:


{
  "nome": "Nome do Personagem",
  "nomeAventureiro": "Nome do Aventureiro",
  "classe": "MAGO",
  "level": 1,
  "forca": 5,
  "defesa": 5
}

Para criar o primeiro item mágico 
{
  "nome": "Nome do Item",
  "tipoItem": "ARMA",
  "forca": 8,
  "defesa": 0
}
